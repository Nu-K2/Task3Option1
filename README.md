## Описание проекта

Проект представляет собой консольное приложение на языке C# (платформа .NET), реализующее **задание 1 из части 3** лабораторной работы — класс «Почтовый адрес организации».

Основной акцент сделан на:
- Разработке класса с приватными полями и публичными методами.
- Инкапсуляции (изменение состояния объекта только через методы).
- Управлении жизненным циклом объектов (создание и уничтожение).
- Организации интерактивного меню для демонстрации работы всех методов класса.

---

## Реализованное задание

### Задание 1. Класс «Почтовый адрес организации»

Требуется описать класс «Почтовый адрес организации» с методами:
- **Изменение составных частей адреса** (страна, город, улица, дом, индекс).
- **Создание и уничтожение объектов** этого класса.

Обязательно наличие меню, через которое можно проверить работу всех методов класса.

---

## Функциональность

Программа предоставляет пользователю интерактивное меню со следующими возможностями:

| Пункт | Действие |
|-------|----------|
| 1 | **Создать адрес** — ввод страны, города, улицы, дома и индекса. Объекту автоматически присваивается уникальный `Id`. |
| 2 | **Изменить страну** — по `Id` адреса. |
| 3 | **Изменить город** — по `Id` адреса. |
| 4 | **Изменить улицу** — по `Id` адреса. |
| 5 | **Изменить дом** — по `Id` адреса. |
| 6 | **Изменить индекс** — по `Id` адреса. |
| 7 | **Показать адреса** — вывод всех сохранённых адресов. |
| 8 | **Удалить адрес** — уничтожение объекта по `Id`. |
| 0 | **Выход** — завершение сеанса. |

### Валидация ввода

- **Страна, город, улица** — только буквы, непустая строка.
- **Дом** — непустая строка (может содержать буквы, цифры, символы).
- **Индекс** — только цифры, непустая строка.
- **Id** — целое число; при вводе несуществующего `Id` программа предложит повторить ввод; пустая строка — отмена операции.

## Класс `PostAddress`

### Поля и свойства

| Свойство | Тип | Описание |
|----------|-----|----------|
| `Id` | `int` | Уникальный идентификатор (автоинкремент). |
| `Country` | `string` | Страна. |
| `City` | `string` | Город. |
| `Street` | `string` | Улица. |
| `Building` | `string` | Дом. |
| `Index` | `string` | Почтовый индекс. |

Все свойства имеют `private set` — изменение возможно только через методы класса.

### Конструктор

```csharp
public PostAddress(string country, string city, string street, string building, string index)
```

- Присваивает уникальный `Id` (статический счётчик `_idCounter`).
- Инициализирует все поля.

### Методы изменения

```csharp
public void ChangeCountry(string value)
public void ChangeCity(string value)
public void ChangeStreet(string value)
public void ChangeBuilding(string value)
public void ChangeIndex(string value)
```

### Метод вывода

```csharp
public void PrintAddress()
```

Выводит в консоль все поля адреса в форматированном виде.

## Особенности реализации

- **Инкапсуляция:** поля класса `PostAddress` недоступны для прямого изменения извне — только через методы `Change*`.
- **Уникальность Id:** статический счётчик `_idCounter` гарантирует, что каждый созданный адрес получит уникальный идентификатор.
- **Уничтожение объектов:** реализовано через метод `addresses.Remove(address)` — объект удаляется из списка и становится недоступным для дальнейших операций (сборщик мусора освободит память).
- **Отмена операций:** при вводе `Id` можно нажать Enter для отмены текущего действия.
- **Меню:** реализовано через `switch`, обрабатывает некорректный ввод без аварийного завершения программы.
